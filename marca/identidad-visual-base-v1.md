## Alcance de esta decisión

Esta decisión fija la dirección visual base para el desarrollo web de **Asis Marlo — Esencia, Piel y Luz**. No rediseña el logo, no selecciona todavía familias tipográficas definitivas y no sustituye el trabajo posterior de Dirección de Arte/UX/UI.

El logo actual de Asis Marlo se conserva como punto de partida. En esta fase no está autorizado su rediseño.

## Intención visual

La identidad debe sentirse:

- femenina;
- íntima;
- elegante;
- artística;
- cálida;
- natural;
- contemporánea;
- profesional;
- auténtica.

Debe evitar una estética excesivamente rosa, romántica, glamour, dorada o propia del boudoir convencional. La fotografía es protagonista; el sistema gráfico acompaña y no compite.

## Paleta aprobada

### Carbón / espresso — `#292522`

Color principal para textos, encabezados, botones y elementos importantes. Sustituye al negro puro como color predominante de interfaz.

`#000000` puede conservarse cuando el logo lo requiera.

### Marfil cálido — `#F5F0E9`

Color principal de fondos y base predominante de la página. Debe aportar luz, calidez y amplitud.

### Arena / piedra — `#D8C9BA`

Color secundario para bloques, separadores, fondos alternativos, detalles gráficos y elementos de apoyo.

### Rosa viejo / nude — `#A9827C`

Acento femenino de uso moderado: botones secundarios, pequeños detalles, enlaces, iconos o elementos destacados. No debe convertirse en color dominante.

### Champagne apagado — `#B49A78`

Acento muy puntual. No utilizar dorado brillante ni recursos que comuniquen lujo ostentoso. Debe sentirse sofisticado y discreto.

## Relación conceptual con la marca

- **ESENCIA** → tierra, arena, tonos orgánicos.
- **PIEL** → nude, rosa viejo, tonos cálidos y naturales.
- **LUZ** → marfil, crema y champagne suave.

Referencia sensorial rectora:

> **piel + lino + madera + luz natural entrando por una ventana + fotografía editorial**

Esta referencia expresa una sensación material y editorial. No obliga a utilizar texturas literales de lino o madera como fondos decorativos.

## Fondos y contraste

Priorizar fondos claros y cálidos.

La web no debe ser predominantemente negra ni oscura. Se permiten secciones oscuras estratégicas para contraste, pero deben ser excepción y no base del sistema.

## Fotografía

Las fotografías deben tener muchísimo protagonismo.

Criterios:

- espacio amplio alrededor de las imágenes;
- composición editorial;
- navegación limpia;
- evitar exceso de elementos decorativos superpuestos;
- permitir que luz natural, piel, texturas y sombras formen parte de la propia identidad visual;
- no sacrificar la fotografía para exhibir recursos de interfaz.

## Tipografía — principio aprobado, selección pendiente

Debe conservarse conceptualmente el contraste existente en el logo:

- “Asis Marlo” aporta personalidad manuscrita, femenina y artística;
- “Esencia, piel y luz” aporta limpieza y minimalismo.

En web debe existir una combinación equivalente: una tipografía con personalidad para usos editoriales/titulares seleccionados y una tipografía limpia, elegante y muy legible para cuerpo, navegación e interfaz.

Evitar tipografías excesivamente ornamentadas o demasiado románticas.

**La familia o familias tipográficas concretas NO quedan aprobadas por este documento.** El especialista visual deberá proponer opciones compatibles con el logo, legibilidad, rendimiento y accesibilidad; Marca aprobará la selección correspondiente.

## Sensación de llegada

La visitante debe poder percibir algo equivalente a:

> “Aquí hay algo femenino, íntimo y bonito, pero también artístico, profesional y auténtico.”

La experiencia no debe parecer:

- una clínica;
- una tienda de lencería;
- una web de fotografía de bodas;
- una marca de lujo fría;
- una plantilla genérica de boudoir.

Debe sentirse como entrar a un espacio íntimo de fotografía donde la mujer, su historia, su piel y su luz son protagonistas.

## Reglas de interpretación

1. La identidad debe transmitir **Esencia, Piel y Luz**; no basta con aplicar los cinco colores como decoración.
2. `#F5F0E9` funciona como base luminosa predominante salvo justificación específica aprobada.
3. `#292522` es el oscuro principal de interfaz; evitar recurrir automáticamente a negro puro.
4. `#A9827C` es acento, no identidad dominante.
5. `#B49A78` debe ser aún más restringido; nunca convertirlo en “dorado de lujo”.
6. La fotografía tiene prioridad jerárquica sobre ornamento.
7. El logo actual está protegido en esta fase y no debe rediseñarse.
8. “Lino”, “madera” y otras referencias materiales son evocaciones; su uso literal requiere criterio visual, no automatismo.
9. Las propuestas deben evaluarse en contexto fotográfico real, no únicamente como muestras de color aisladas.
10. Una propuesta que termine pareciendo glamour boudoir, joyería de lujo, clínica estética, boda romántica o tienda de lencería debe considerarse desviación de marca aunque utilice la paleta correcta.
